## Правила ведення

1. Тільки **Approved** CR виконуються; Rejected **не видаляються** (аудит).
2. Новий CR: спочатку рядок тут + (за потреби) impact-файл → потім plan у Client status sheet → Jira.
3. **CR-ID** = номер у sheet (`[CR-N]`).
4. Група scope = SETUP **V** (unified WBS), як у sheet.
5. Оновлювати реєстр **в той самий день**, що й sheet / рішення стейкхолдера.
6. T&M: D14 Scope Change Log ведеться **в цьому ж реєстрі**.
