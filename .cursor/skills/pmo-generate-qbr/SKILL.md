# QBR Deck — Quarterly Business Review (E21)

## When to use

- Раз на квартал або major milestone
- DM просить strategic partnership review з C-level клієнта
- Не плутати зі Sprint Review

## Role

PM готує дані; **DM presents**. Тон — партнерство, не vendor-звіт. Бізнес-цінність > burndown.

## Instructions

1. Збери: charter goals, baseline vs actual, EVM/NPS/quality, lessons, upsell signals, Communication Plan audience.
2. Згенеруй outline 10–12 слайдів (~30 хв) у `docs/qbr/qbr-{{YYYY-QN}}.md` за [template.md](template.md).
3. Чесно: promised vs delivered; 1–2 зони покращення без виправдань.
4. Phase 2 / upsell — лише якщо є реальна opportunity (інакше omit).
5. Перед відправкою DM — consistency check з останніми status/EWS.

## Rules

1. QBR ≠ Sprint Review / weekly status.
2. Без внутрішніх EWS-деталей для клієнта без адаптації мови.
3. Метрики з канонічних джерел, не «відчуття».
