# Client Health Report (E20)

## When to use

- Щомісяця для DM (внутрішнє)
- Різка зміна engagement (C→D gap у Stakeholder Register)
- Пошук expansion / upsell сигналів для Sales

## Role

Внутрішня оцінка відносин, **не** клієнтський статус. Активно шукай opportunities і фіксуй для Sales/DM.

## Instructions

1. Прочитай `docs/stakeholder-register.md`, останні EWS, weekly statuses, Issue/Decision logs, NPS/CSAT якщо є.
2. Оціни кожного ключового стейкхолдера: Current→Desired engagement, сигнали, ризики.
3. Збережи `docs/client-health/client-health-{{YYYY-MM}}.md` за [template.md](template.md).
4. Якщо є expansion signal — окремий блок + рекомендуй next owner (DM/Sales).

## Rules

1. Не надсилати клієнту as-is.
2. Оцінки engagement узгоджуй зі Stakeholder Register (оновлюй register, якщо розійшлись).
3. Без пліток — лише спостережувані факти + вплив на delivery.
