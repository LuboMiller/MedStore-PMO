# Template — pmo-generate-lessons-learned

Шаблон: `templates/tl-lessons-learned.md` (індивідуальний запис), рядок реєстру — за зразком `docs/lessons-learned-registry.md`.

**Категорії (рівно одна з шести):** Технічна · Ресурсна · Організаційна · Бізнесова · Комунікаційна · Зовнішня

**Формат тегів:** `#kebab-case`, 3-5 на запис, конкретні (тип проблеми чи домен: `#multi-currency`, `#vendor-dependency`, `#scope-creep`), не загальні (`#bug`, `#issue`) — **і обов'язково з `docs/lessons-learned-tag-taxonomy.md`**, або доданий туди в тому ж прогоні, якщо дійсно новий.

**Формат Джерело:** файл + якір (ID ризику, номер CR, номер спринту, шлях). Приклад: `docs/risk-register.md → R-09`, не "з обговорення на стендапі".

**Формат Дії (таблиця з 4 колонок):** Артефакт | Owner | Дедлайн | **Indicator успіху**. Indicator — спостережуваний або вимірюваний критерій ("0 випадків X за N спринтів", "100% записів мають поле Y"), не побажання ("стане краще"). Якщо є базове значення цього проєкту (скільки разів проблема траплялась досі) — вказати його в дужках для контрасту.
