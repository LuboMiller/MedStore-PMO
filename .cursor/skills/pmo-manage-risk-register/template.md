# Template — pmo-manage-risk-register

> Структура реєстру визначена у шаблоні `templates/tl-risk-register.md`.  
> При створенні нового реєстру — копіювати звідти. При роботі з існуючим — редагувати `docs/risk-register.md`.

### Рядок у реєстрі (ADD)

```
| R-XX | [Категорія] | **[Назва]** — [розгорнутий опис умов виникнення] | [Ймовірність] | [Вплив] | [🔴/🟡/🟢 Рівень] | [Конкретна митигація + тригер] | [Власник] | 🟡 Активний | [Дата появи = сьогодні] | [Останнє оновлення = сьогодні] |
```

**Дата появи** фіксується один раз при ADD і ніколи не змінюється. **Останнє оновлення** — дата останньої фактичної зміни (статус, ймовірність, вплив, митигація, власник); перегляд без зміни не оновлює це поле.

### Рядок у Mitigation Plan (для 🔴/🟡 ризиків)

```
| R-XX | [Конкретні дії що знижують ймовірність або вплив] | [Умова активації — метрика або подія] | [Роль] | [Дії якщо ризик реалізувався попри митигацію] |
```

### Рівень = Ймовірність × Вплив

| | Низький | Середній | Високий | Критичний |
|---|---|---|---|---|
| **Висока** | 🟡 Високий | 🟡 Високий | 🔴 Критичний | 🔴 Критичний |
| **Середня** | 🟢 | 🟡 Високий | 🟡 Високий | 🔴 Критичний |
| **Низька** | 🟢 | 🟢 | 🟡 Високий | 🟡 Високий |

### Після кожної зміни — оновити зведення

```
| 🔴 Критичний | N | R-XX, R-XX |
| 🟡 Високий   | N | R-XX, R-XX |
| 🟢 Під контролем | N | — |
| ⚫ Закритий  | N | — |
```
