# Чекліст: Перед відправкою weekly статусу клієнту

Виконай перед кожною відправкою статусу.

---

## Зміст
- [ ] Всі виконані задачі відображені коректно
- [ ] Статус по кожному треку актуальний (перевірив у Jira)
- [ ] Ризики та блокери описані нейтральною мовою
- [ ] Немає технічного жаргону якщо аудиторія PO або CMO
- [ ] Питання до клієнта сформульовані чітко

## Тон і формат
- [ ] Мова відповідає аудиторії (PO vs CTO+CMO)
- [ ] Тон конструктивний — не панічний, не занадто оптимістичний
- [ ] Обсяг не перевищує 1 сторінку
- [ ] Структура відповідає шаблону

## Технічна перевірка
- [ ] Дати спринту і тижня вказані коректно
- [ ] Всі числа (SP, %) актуальні
- [ ] Посилання на Jira / документи працюють (якщо є)

## Фінал
- [ ] Документ прочитаний вголос (перевірка тону)
- [ ] Відправляти в: [Slack / Email — канал клієнта]
